# 📦 Stash

A simple list / tracker app. Add things to your stash, tick them off when
you're done, and remove them when you don't need them anymore. Your list is
saved in your browser automatically.

Built with plain **HTML, CSS and JavaScript** — no complicated tools needed.

## The files

| File | What it does |
| --- | --- |
| `index.html` | The structure of the page (the headings, the input box, the list). |
| `styles.css` | How everything looks (colours, spacing, fonts). |
| `script.js` | How it works (adding, ticking and deleting items). |

Each file has comments inside explaining what the different parts do, so
it's a good one to read through and tinker with.

## How to run it on your own computer

You don't need to install anything. Just **open `index.html`** in a web
browser (double-click the file, or drag it into a browser window).

To make changes: open the files in a text editor (like VS Code), edit them,
save, and refresh the browser to see the change.

## Putting it online with Vercel

This project is connected to GitHub. Every time new code is pushed to
GitHub, Vercel will automatically publish the latest version to a live web
address you can share.

First-time setup (only needed once):

1. Go to [vercel.com](https://vercel.com) and sign up with **GitHub**.
2. Click **Add New… → Project**.
3. Find **`stash-app`** in the list and click **Import**.
4. Leave the settings as they are and click **Deploy**.

That's it — Vercel gives you a link, and it updates itself whenever the code
changes on GitHub.

## Ideas to make it your own

- Change the title, emoji and colours (look in `styles.css`).
- Add categories or a "priority" star to each item.
- Change the placeholder text in the input box (in `index.html`).
